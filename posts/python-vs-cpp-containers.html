Python vs C++ Container Mapping

A quick reference for the most common Python containers and their closest C++ equivalents, with examples for list, tuple, deque, dict, and set.

May 3, 2026 • 5 min read • Python / C++

Common container mappings

Python C++
list std::vector<T>
tuple std::array<T, N>
collections.deque std::deque<T>
dict std::unordered_map<Key, T>
set std::unordered_set<T>

list

Python list is the closest common match to C++ std::vector.

numbers = [1, 2, 3]
numbers.append(4)
print(numbers)  # [1, 2, 3, 4]

#include <vector>
#include <iostream>

int main() {
    std::vector<int> numbers = {1, 2, 3};
    numbers.push_back(4);
    for (int n : numbers) {
        std::cout << n << ' ';
    }
}

tuple

Python tuple is an immutable ordered collection, similar to a fixed-size C++ std::array.

point = (10, 20)
print(point[0], point[1])

#include <array>
#include <iostream>

int main() {
    std::array<int, 2> point = {10, 20};
    std::cout << point[0] << ' ' << point[1];
}

collections.deque

Deque provides fast push/pop at both ends in Python and C++.

from collections import deque

queue = deque([1, 2, 3])
queue.appendleft(0)
queue.append(4)
print(queue)  # deque([0, 1, 2, 3, 4])

#include <deque>
#include <iostream>

int main() {
    std::deque<int> queue = {1, 2, 3};
    queue.push_front(0);
    queue.push_back(4);
    for (int n : queue) {
        std::cout << n << ' ';
    }
}

dict

Python dict maps directly to C++ std::unordered_map for general key-value use.

data = {"name": "Sambhav", "role": "engineer"}
print(data["name"])

#include <unordered_map>
#include <string>
#include <iostream>

int main() {
    std::unordered_map<std::string, std::string> data = {
        {"name", "Sambhav"},
        {"role", "engineer"}
    };
    std::cout << data["name"];
}

set

Python set and C++ std::unordered_set are both hash-based unique collections.

colors = {"red", "green", "blue"}
colors.add("yellow")
print("green" in colors)

#include <unordered_set>
#include <string>
#include <iostream>

int main() {
    std::unordered_set<std::string> colors = {"red", "green", "blue"};
    colors.insert("yellow");
    std::cout << (colors.count("green") ? "true" : "false");
}
